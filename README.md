# probingLM
A probing wrapper/codebase for gpt-2 style models

`probingLM/src/train_native_lens.py` and `train_native_lens.sh`: code and slurm script for training native lens

`probingLM/src/train_native_lens_ddp.py` and `parallel.sh`: code and slurm script for training native lens with DistributedDataParallel (still in testing)
